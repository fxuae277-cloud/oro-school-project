# مشروع أورو — ORO

منصة طلابية لتصميم الإعلات والبوسترات بسهولة، مبنية بـ React + Vite + TypeScript + Tailwind CSS.

## عن المشروع

هذا مشروع مدرسي تعليمي، طُوِّر كجزء من متطلبات مادة المشاريع المدرسية.
المنصة تتيح للطلاب تصميم إعلانات جاهزة باستخدام قوالب معدة مسبقًا.

## التقنيات

- React 18 + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- React Router

## التشغيل

```bash
npm install
npm run dev
```

## البناء للإنتاج

```bash
npm run build
```
